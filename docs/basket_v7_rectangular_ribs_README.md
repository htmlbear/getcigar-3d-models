# Basket v7 Standard — прямоугольные усиления у дна вместо косых косынок

## Задача

Пользователь указал на проблемные наклонные треугольные усилители нижних передних углов корзины, которые при печати PETG соплом 0,8 мм иногда образуют браки из-за нависаний. В **стандартной корзине 350 мм** заменить эти скосы вертикальными прямоугольными рёбрами, опирающимися на дно, с 90-градусным переходом. Удлинённую корзину Long 376 мм пока **не изменять**.

## База и геометрия

- Точный исходный STL: `stl/L_gridfinity_30mm_center_rib/basket_140x350_v5_height98.stl`.
- Новый STL: `stl/L_gridfinity_30mm_center_rib/basket_140x350_v7_rectangular_ribs.stl`.
- Размеры неизменны: **140 × 350 × 98 мм**.
- В оригинальной v2 конструкции наклонные усилители на обоих длинных боках представляли собой треугольные косынки с координатами XZ: `(1,5;3,8) (11;3,8) (1,5;12)`, зеркально справа. В v5 эти усиления унаследованы.
- Удалена только часть этих треугольных косынок **выше непрерывного нижнего соединительного пояса Z=4,5 мм и внутри номинальной боковой стенки X=2,4 мм**. Сохранены сами боковые стенки и напольные соединительные пояса.
- Добавлены **прямоугольные непрерывные рёбра по обеим длинным стенкам**: слева X=1,5…5,75 мм, справа X=134,25…138,5 мм; Z=3,7…12 мм, Y=0…350 мм. Нижняя часть каждого ребра перекрывает исходный соединительный пояс для надёжного монолитного объединения; новое вертикальное ребро опирается на нижнюю основу и печатается послойно без косого нависания.
- Выемка для пальцев с плавной окантовкой, площадка этикетки 75×40 мм, рисунок сот, центральная сетка пола, передняя и задняя части остаются на исходных координатах.
- Исходные STL всех других версий не перезаписаны, **Basket Long v6 (376 мм) не затронута**.

## Автоматические проверки

GitHub Actions прошёл успешно. Проведены проверки:

- **Одна замкнутая объёмная сетка**, непротиворечивая ориентация граней.
- Наружные размеры **140×350×98 мм** как у оригинала.
- Не изменена геометрия передней площадки этикетки и верхней выемки/бортика в контрольных точках.
- Не изменён рисунок центральной решётки дна в контрольных точках.
- На 5 участках по длине обе новые вертикальные рёбра непрерывны, прежний нижний пояс сохранён, а нависающая часть треугольных косынок больше не присутствует.
- CAD объём исходной v5: **204 708,51 мм³**.
- CAD объём новой v7: **204 018,45 мм³**, уменьшение на **690,06 мм³**. Реальная масса/время печати в слайсере ещё не проверены.

## Перед серией

Открыть новый STL в Elegoo Slicer и сравнить нарезку с v5 при **том же профиле** (PETG, сопло 0,8 мм). Посмотреть на боковые рёбра у дна в режиме послойного Preview: все линии должны опираться на предыдущие, без боковых мостов. После этого сначала напечатать одну корзину, проверить стыковку с Box v10 Light, жёсткость и свободный ход. Проводимые геометрические проверки не доказывают прочность при полной загрузке.
