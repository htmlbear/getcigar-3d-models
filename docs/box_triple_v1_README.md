# Box Triple v1 — единый модуль на 3 стандартные корзины

**Статус: ЭКСПЕРИМЕНТ, НЕ ПЕЧАТАЛСЯ.** Основой является точная STL-сетка **Box v10 Light**. Корзины, оригинальные коробки и все архивные версии НЕ изменяются.

## Конструкция и совместимость

- Три одинаковых отсека, расположенных **бок о бок**, для существующих **Basket v5/v7 140×350×98 мм**.
- Вся исходная геометрия Box v10, включая сотовые стенки, нижний задний ограничитель и верхние/нижние посадочные профили, сохраняется точно; **только две соседние стенки объединяются** настоящим Boolean union.
- Каждая исходная коробка X=0..150 сдвигается по X на 0, 148 или 296 мм. Итого 150+2×148 = **446 мм**, а не 450 мм.
- В каждой секции исходный коридор корзины (в печатных координатах) X=смещение+4..146 (142 мм), Y=10..110 (100 мм) не пересекается ни с одной соседней моделью. **Корзины не масштабировать.**
- Соседние свободные оболочки v10 центральной сотовой стенки имеют по 1,65 мм. На общей перегородке при шаге 148 мм исходные наружные оболочки накладываются: одна от 148,35 до 150 мм, другая от 148 до 149,65 мм. Их объединение занимает **2 мм** в этом свободном поле, перекрытие **1,3 мм**; в усиленных поясах местная геометрия толще. **Нельзя трактовать всю перегородку как постоянные 2 мм**.
- Поперечное оформление и вентиляционные соты определяются исходной v10, не перерисовываются.
- Длинная Basket LONG 376 мм **не является полностью совместимой** с корпусом глубиной 350 мм; вопрос её выступания остаётся открытым.

## Геометрия печати

| Параметр | Значение |
|---|---:|
| Одна Box v10, печатная ориентация | 150×120×350 мм |
| Три отдельные Box v10 в ряд | 450×120×350 мм |
| **Box Triple v1 без поворота** | **446×120×350 мм** |
| Угол на столе вокруг вертикальной Z | 45° |
| **Пятно на столе после поворота** | **400,22×400,22 мм** |
| Печатная область Neptune 4 Max | 420×420×480 мм |
| Запас до границ XY при центрировании | ≈9,89 мм на каждую сторону |
| Высота печати | 350 мм |
| Шесть тройных модулей по 120 мм | 720 мм без учёта особенностей стыка |

**Критично:** печатать на торце, с длинной осью 350 мм вертикально, точно так же, как исходную v10. **Не класть на длинный бок**: ориентация сот и нависаний становится другой. STL уже развёрнут на 45° и центрирован в поле 420×420 мм. Слайсер может автоматически переместить модель; проверяй место и все skirt/brim на первом слое. Боковая кайма 10 мм с таким полем может выйти за рабочую зону.

## Как проверить

1. Получить новый STL с помощью Python / GitHub Actions. Проверить, что он **замкнут и состоит из одного тела**, имеет 446×120×350 мм до поворота и 400,22×400,22×350 мм на столе.
2. В **Elegoo Slicer** открыть готовый STL и проверить реальное размещение на рабочей области 420×420 мм, места для юбки/каймы и безопасные перемещения головки.
3. Нарезать три отдельные v10 и один Triple v1 с **одинаковыми параметрами сопла PETG 0,8 мм**. Сравнить полную массу и время печати по G-code. CAD-объём и «полнотелый PETG-эквивалент» не равны реальному расходу филамента.
4. Просмотреть **первый слой и переходы общих перегородок**, линии периметров (в том числе участки номинальных 2 мм), стыки сот, потенциальные мосты и неформируемые участки. Не предполагать печать без поддержек только из-за геометрической проверки.
5. Сначала напечатать **невысокий посадочный фрагмент**, проверить три уже имеющиеся корзины и сопряжение с другим Triple; затем один целый модуль.
6. Испытать жёсткость в нагруженном состоянии и вертикальную стыковку шести уровней (18 корзин). Пока испытаний нет, не утверждать надёжность многоярусной установки.

**Ограничение:** из трёх точных боксов v10 за счёт объединения соседних стенок получается монолит, но это не полная новая топологическая оптимизация корпуса. После первой нарезки можно отдельно обсуждать более экономичную специально переработанную конструкцию. Старые формы корзин при этом оставлять неизменными.
