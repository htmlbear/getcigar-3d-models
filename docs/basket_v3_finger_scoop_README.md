# GetCigar Basket v3 — плавная выемка для пальцев

**Основа:** последняя корзина `v2` с сетчатыми стенками, 30-мм решёткой дна, центральным ребром 6×8 мм, усиленными соединениями со стенками и несдвигаемой площадкой под этикетку 75×40 мм.

Эта ревизия изготовлена **только вычитанием материала из готового STL v2**, а не перерисовкой корзины. Архивные файлы v2 не изменялись.

## Выемка по предоставленной разметке

- **Передняя короткая стенка, Y=0**.
- U-образная плавная центральная выемка: по оси X от **10 до 130 мм**.
- Глубина по высоте от Z=100 мм у краёв до **Z=78 мм** в центре, то есть **22 мм**.
- В центральном участке X=55…85 мм выемка широкая, дно на Z=78 мм.
- Левый и правый скаты имеют кубическую кривую с плавными касательными, чтобы не было острых внутренних углов.
- Выемка пересекает только переднюю стенку, в локальной зоне **Y=-1…9 мм**; боковые стенки, дно и задний торец не затронуты.
- Площадка под этикетку **75×40 мм**, X=32,5…107,5, Z=30…70 мм, остаётся целой. Минимальный зазор по высоте до выемки — **8 мм**.

## Совместимость

Внешние габариты корзины и посадка в бокс не меняются: **140×350×100 мм**. Это номинальные максимальные размеры старого STL. Края, дно, рёбра, боковые стенки и существующая маркировочная площадка остаются на тех же координатах; меняется только контур верхней передней стенки.

Модель предназначена для использования со старыми боксами, включая Box v10 Light; реальную посадку нужно подтвердить печатью.

## Проверки

Генератор GitHub Actions экспортирует STL и проверяет:

- Один замкнутый связный объём (watertight) с корректной ориентацией граней.
- Совпадение наружных габаритов `140 × 350 × 100 мм` с v2.
- Объём стал меньше, поскольку удалён материал передней стенки.
- Площадка для этикетки и нижние/боковые опорные точки сохранены.

Перед печатью полной партии открыть файл в Elegoo Slicer, проверить верхнюю часть фасада на наличие тонких нитей, чрезмерных мостов и правильное отображение выемки. Оценка экономии PETG и времени зависит от настроек сопла, слоя, потока, поддержки и количества стенок.

**Не считать модель физически испытанной:** корзина остаётся прототипом. При выдвижении за выемку надо проверить прочность передней верхней перемычки и соединения фасада с боковыми стенками, особенно при полной загрузке.
