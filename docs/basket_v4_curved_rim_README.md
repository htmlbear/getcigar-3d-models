# Basket v4 — плавная выемка с цельным защитным бортиком

## Изменение по рисунку пользователя

У v3 после простого U-образного выреза остались торчащие свободные концы сотовых перемычек. Они неудобны для пальцев, могут легко ломаться и не образуют законченного верхнего обода.

**Исправление v4:** к готовой сетке v3 геометрически приварена (Boolean union) **сплошная изогнутая окантовка**, проходящая ровно по U-образной выемке и до обоих верхних углов. Верхняя линия бортика плавно повторяет зелёную линию на пользовательском рисунке. Обод связывает концы сот, исключает открытые «штырьки» на линии выемки и лучше распределяет усилие при вытягивании корзины.

## Размеры и границы изменений

- Исходник: точный STL `basket_140x350_v3_finger_scoop.stl`; все детали вне передней верхней части в неизменённых координатах.
- Габариты корзины: **140 × 350 × 100 мм**, не увеличены.
- Передняя стенка: Y=0; глубина окантовки в сторону корзины **9,2 мм**, без выступа наружу за Y=0.
- Контур выемки: X=10…130 мм, центральная нижняя линия Z≈78 мм, широкое плоское дно X=55…85 мм; плавные скаты через кубическую smoothstep-кривую.
- Сплошной бортик: **5,4 мм** от линии U-выреза вниз. Небольшой перекрывающий допуск **0,3 мм** внутри выреза для монолитного соединения, но максимальная высота остаётся **100 мм**.
- Сплошные боковые участки окантовки соединяются с прежними верхними углами (X=0…10 и X=130…140).
- Площадка под этикетку **75 × 40 мм** при X=32,5…107,5, Z=30…70 мм сохранена без изменения; даже в центре самый низ окантовки расположен при Z=72,6 мм, то есть выше этикетки.

Дно, продольные стенки, сотовый рисунок ниже выемки, усиления, рёбра и посадка корзины в существующий Box v10 Light не меняются.

## Проверки и ограничения

Автоматическая процедура проверяет замкнутость STL (watertight), положительный объём, единую связную геометрию, исходные внешние габариты, сплошной материал по всей длине бортика в 45 поперечных контрольных сечениях, свободный проём над бортиком и неизменность площадки под этикетку. Отдельно проверяется отсутствие изменений в остальной корзине.

**Не начинать массовую печать без проверки предпросмотра Elegoo Slicer.** При сопле 0,8 мм нужно оценить, не осталось ли коротких нависающих перемычек сотовой структуры в местах прилегания бортика. Прочная геометрия CAD не гарантирует отсутствия проблем печати или достаточной жёсткости при захвате и нагрузке: сначала печатать одну корзину, проверить плавность края рукой и прочность вытягивания с нагрузкой. Сравнивать массу/время с v3 и v2 только при одинаковом профиле нарезки.
