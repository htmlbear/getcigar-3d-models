# Box 80 v10 Light — ещё легче при прежней посадке

## Цель

После нарезки v9 Light в Elegoo Slicer пользователь сообщил **334 г на один бокс** при существующем профиле PETG/сопла 0,8 мм. Три таких бокса потребуют **1002 г**, без запаса на погрешности. Целевой ориентир пользователя — ≤320 г/шт., чтобы из одной катушки 1 кг можно было уверенно изготовить три бокса.

## Что сделано

- Использован **полный исходный STL v9** без масштабирования или перерисовки.
- Дополнительно углублены **только внутренние поверхности свободных длинных стенок**: остаточная толщина центральных ячеистых полей уменьшена с **2,1 до 1,65 мм**.
- Изменения ограничены точными координатами: Y=17…103, Z=12…338, X=1,65…2,1 и X=147,9…148,35 в ориентации печати.
- Снаружи остаётся исходный контур. Верх/низ, стыковочные элементы, корзинный проход, соединительные пояса, углы, торцевые рамки и существующий рисунок сот сохранены. Файлы версий v8/v9 не затронуты.

## Автоматическая проверка

GitHub Actions успешно собрал STL; проверены: замкнутость, единое связное тело, положительный объём, согласованность нормалей, равные границы с v9 и сохранение усиленных торцевых участков.

- Размеры STL для печати: **150×120×350 мм**.
- CAD-объём v9: **319 843,87 мм³**.
- CAD-объём v10: **310 657,38 мм³**.
- Убрано по объёму **9 186,49 мм³**, то есть **2,87% объёма v9**.
- При условной плотности PETG 1,27 г/см³, это соответствует **≈11,67 г сплошного пластика**.

**Это не точный прогноз расхода по G-code.** Расход слайсера зависит от проходов/толщины линий, количества периметров, типа генератора тонких стенок, заполнения и дополнительных структур. Приблизительная арифметическая оценка **334 − 11,7 ≈ 322,3 г** пока не проверена. Если расход окажется ≤333 г на бокс с учётом поддержек/каймы, три экземпляра теоретически поместятся в 1 кг, но для реальной катушки нужен запас.

## Предостережения перед производством

- **1,65 мм — тонкая стенка для сопла 0,8 мм.** Проверь нарезку в Elegoo Slicer: количество реальных линий, пустоты и слабые участки. Поток 20 мм³/с и стабильный профиль печати пока не менять. Не начинать серию из трёх экземпляров без первого пробного бокса.
- Нужно проверить фактическую совместимость старой и новой печати, особенно вставной стык двух корпусов, геометрию корзинного проёма и жёсткость под нагрузкой. Геометрическая CAD-проверка **не доказывает механическую прочность**.
- Для колонны из шести загруженных боксов требуется испытать жёсткость и вертикальную деформацию PETG, особенно в облегчённых стенках.
- Пользовательская цель ≤320 г **не подтверждена** до новой нарезки. Если слайсер покажет значение больше, сперва измерить расход по типам экструзии, а не бесконтрольно ослаблять несущие пояса.
