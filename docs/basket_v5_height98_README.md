# Basket v5: высота 98 мм, без изменения остальных элементов

По результатам физического использования пользователь сообщил, что корзина v4 слишком плотно входит в бокс по вертикали. Требуется уменьшить **только высоту** с 100 до 98 мм, сохраняя остальные размеры, геометрию и функциональные элементы.

## Изменение

- Исходный файл: `stl/L_gridfinity_30mm_center_rib/basket_140x350_v4_curved_rim.stl`.
- Новый файл: `stl/L_gridfinity_30mm_center_rib/basket_140x350_v5_height98.stl`.
- Печатаемая корзина была 140 × 350 × 100 мм и стала **140 × 350 × 98 мм**.
- Изменение выполнено **отрезанием ровно верхних 2 мм** по плоскости Z=98 мм. Глобального масштабирования нет, ширина и длина не меняются.
- Передняя U-образная выемка с цельным плавным бортиком сохранена там, где расположена ниже уровня Z=98 мм. Часть верхней кромки на высоте 98–100 мм, естественно, срезана, включая крайние участки бортика. Геометрия ниже 98 мм не менялась.
- Площадка этикетки 75×40 мм, дно, передние/задние и боковые стенки ниже Z=98 мм, продольные рёбра и соты полностью сохранены.
- v2, v3 и v4 оставлены в репозитории без изменений.

## Проверки

GitHub Actions строит STL с помощью Manifold-Boolean и автоматически сравнивает v5 с v4, ограниченной плоскостью Z=98 мм. Пройденные проверки:

- Габариты ровно 140×350×98 мм.
- Замкнутая одночастная сетка, согласованная ориентация треугольников, положительный объём.
- Проверка двух Boolean-разностей (в обе стороны) **ниже Z=98 мм: 0 мм³ расхождения**.
- Оригинальный CAD-объём v4: **208 116,905 мм³**.
- Новый CAD-объём v5: **204 708,511 мм³**.
- Убрано **3 408,394 мм³** геометрического объёма.

Реальный расход пластика и печатаемость проверить в Elegoo Slicer. Следует также проверить физическую посадку в Box v10 и удобство верхнего бортика. В отличие от предыдущего 100-мм варианта, у v5 верхние крайние кромки уже на высоте 98 мм.
