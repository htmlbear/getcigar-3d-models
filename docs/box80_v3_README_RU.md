# GetCigar: Box 80 v3 из ОРИГИНАЛЬНОГО box_80.stl

## Содержание
- box_80_160x350x120_ends_stacking.stl — основная модель, **в положении для хьюмидора** (Ш×Г×В = 160×350×120 мм).
- box_80_print_on_end_160x120x350.stl — **та же модель, повёрнута для печати на торце** (основание 160×120 мм, высота 350 мм).
- six_box80_on_420x420_plate.stl — **6 экземпляров** стоя на торце, сетка 2×3 на столе 420×420 мм; смотрите зазоры/адгезию/опоры.
- box_80_160x350x120_ends_stacking.scad — редактируемая CSG-модификация исходного STL.
- box_80_original_transform_for_v3.stl — трансформированная исходная сетка (соты и исходные боковые края сохранены).
- transform_box_80.py — пересчёт исходного STL в новые размеры и оси.
- box_80.stl — оригинальный файл пользователя, без изменений.

## Геометрия
- Наружные габариты ОДНОГО бокса: 160×350×120 мм, включая вертикальные выступы.
- Основное тело по высоте 116 мм и 4-мм вертикальные соединители на верхней поверхности.
- Лишь вертикальная стыковка: 4 штыря Ø8 мм + 4 нижних ответных гнезда Ø8.6 мм; расчётный вертикальный шаг 116 мм.
- НЕТ боковых замков/скоб. Боковые сотовые стенки — из оригинального STL. Четыре основных панели корпуса: два боковых сотовых борта, сплошные верх и низ толщиной 4 мм.
- Проход спереди/сзади: 144×104 мм; боковая ширина корзины 140 мм, высота 100 мм.
- Корзину не изменяли. Длина корзины вместе с ручкой = 350 мм. При наружной глубине бокса ровно 350 мм нельзя поставить глухую заднюю стенку: сохранена задняя рамка с проёмом.
- Внутренняя опорная плоскость корзины z=6 мм, внутренняя нижняя плоскость крыши z=110 мм: 104 мм внутреннего свободного пространства.
- Оригинальные продольные соты сохранены, боковой профиль несколько сужен в толщине для увеличения внутренней ширины, но внешний контур сохранён.
- Нижняя и верхняя кромки из оригинала сохранены и дополнены ответными штырями/гнёздами, поскольку исходную геометрию простой масштабированием нельзя было надёжно состыковать под нагрузкой.

## Проверки
- Геометрический STL: замкнут, одна связная оболочка; внешние габариты подтверждены программно.
- Проверены пересечения STL корзины и бокса при Y=0,-50,-150,-300 мм (объём 0 мм³ при точной посадке).
- Проверено пересечение двух боксов при вертикальном шаге 116 мм (объём 0 мм³).
- Шесть корпусов можно расположить на столе 420×420 мм в ориентации на торце: 2 по ширине и 3 по глубине столика. В итоговом STL координаты: x=20 и 240, y=10,150,290, общий занимаемый прямоугольник x=20..400, y=10..410; при кайме 5 мм минимальный остаточный край стола по Y=5 мм, проверяйте эффективную область вашего принтера.

## Печать и эксплуатация — важные оговорки
- НЕ ПРОВЕРЯЛОСЬ в ELEGOO Slicer. Не гарантировать отсутствие поддержек, особенно для некоторых переходов сотовой сетки или соединителей.
- Высота печати 350 мм, даже при 6 экземплярах, требует тщательного первого слоя и возможной каймы/brim. Не начинайте сразу печатать шесть: сначала один короткий тест или один корпус.
- При печати PETG по 6 экземпляров общая длительность может быть БОЛЬШЕ, чем при одиночной печати; выгода — меньше ручных переналадок.
- Соединители имеют радиальный зазор 0,3 мм; проверить реальную посадку и усадку PETG.
- Геометрическая проверка не является испытанием на прочность. 6 ярусов могут деформироваться под нагрузкой; испытать реальные боксы и закрепить сборку от опрокидывания.
- Для поддержки корзины по дну учитывайте возможное трение PETG по PETG; при необходимости обработайте поверхность/используйте тонкие накладки.
