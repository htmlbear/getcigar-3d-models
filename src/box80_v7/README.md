# Box 80 v7 — исправлена посадка боксов по вертикали

**Основа:** готовый STL версии v6. Никаких изменений v6 и старых моделей.

## Почему сделано

После реальной печати двух тестовых срезов пользователь измерил:
- ответное нижнее отверстие (самое узкое место): **134 мм**;
- верхнюю вставную часть: **135,111 мм**;
- требуемый общий зазор: **примерно 2 мм**, по ~1 мм с каждой стороны.

В исходном STL v6 верхний сопрягаемый рельеф местами достигает ширины около **136,222 мм** на концах глубины, хотя центральные участки имеют ширину около 134 мм. Поэтому корректируется именно крайний габарит всего верхнего рельефа.

## Исправление

- Самая широкая часть верхнего рельефа после изменения: **132 мм**, X=9…141.
- Затронуты **только** вершины верхнего посадочного рельефа на высоте Y≥116,8 мм (в ориентации файла для печати).
- Точки центрального сотового узора в X=11,1521…138,8479 мм остаются на месте.
- Нижний ответный паз, наружные размеры **150×120×350 мм в ориентации печати**, усиления, гладкие стенки, продольные полосы, задняя нижняя рамка, корзина, проход для корзины и другие элементы не изменялись.
- Единственный выходной STL: `stl/box80_v7_PRINT_ON_END_150x120x350.stl`.
- Источник воспроизводимой операции: `src/box80_v7/build_box80_v7.py` (использует `trimesh`, `numpy`).

## Проверки и осторожность

Геометрию STL нужно проверять на замкнутость, согласованность ориентации граней, одно связное тело и сохранение габаритов. После этого — **распечатать два коротких среза именно v7**, установить один на другой и проверить практический зазор. Из-за усадки/разбухания PETG и особенностей нарезки физический зазор может отличаться от номинальных 2 мм. Прочность стопки из 6 ярусов этой проверкой не подтверждается.
