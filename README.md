# getcigar-3d-models

## Актуальная модель модульного бокса

**Последняя разработанная версия: v9 Light** — на основе v8, с дополнительными сотами и облегченными изнутри боковинами. Сборка STL и геометрические проверки пройдены. **Статус: экспериментальная, масса в Elegoo Slicer и прочность реальной печати ещё не подтверждены.**

- [STL v9 Light для печати на торце](stl/box80_v9_light_PRINT_ON_END_150x120x350.stl)
- [Исходник OpenSCAD v9 Light](src/box80_v9/box80_v9_light.scad)
- [Описание, совместимость, ограничения и тесты v9](docs/box80_v9_light_README.md)

**Предыдущая проверенная геометрия — v8** (без облегчения внутренних стенок):

- [STL v8](stl/box80_v8_honeycomb_sidewalls_PRINT_ON_END_150x120x350.stl)
- [OpenSCAD v8](src/box80_v8/box80_v8_honeycomb_sidewalls.scad)
- [Описание v8](src/box80_v8/README.md)

**Правило версий:** каждая новая модель `v9`, `v10` и т. д. получает собственные файлы с номером версии в имени; архивные STL никогда не перезаписываются. README обновляется с явным указанием актуальной версии.

## Сначала прочитать

**[DRAWER_REQUIREMENTS.md](DRAWER_REQUIREMENTS.md)** — единое техническое задание на ящики, направляющие и крепления. Перед любыми изменениями моделей OpenSCAD/STL сначала читать этот файл. Изменения требований и результаты физической печати вносятся туда же.

## История прототипов

- `src/`, `stl/` — исходные модели OpenSCAD и экспортированные STL.
- `docs/` — инструкции к отдельным экспериментальным версиям.

Предыдущие сборки v1.0 и v1.1 экспериментальные, не рассчитаны на эксплуатацию с нагрузкой. Новый прототип должен учитывать замечания в `DRAWER_REQUIREMENTS.md`.
